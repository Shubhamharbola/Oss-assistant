Oss-assistant

Helping developers make their first meaningful open-source contribution.

## Why I'm Building This

After trying to make my own first open-source contribution, I realized the hardest part wasn't writing code—it was understanding where to begin.

This project is my attempt to understand that problem and build a tool that makes the journey easier.

## Goals

- Learn production backend engineering
- Understand GitHub APIs
- Practice system design
- Build in public
- Create a project I'm proud to discuss in interviews
